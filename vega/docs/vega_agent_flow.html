API Endpoints

MethodPathDescription
POST/projects/parse-messageLLM classifies intent (create/update/unclear) & extracts total in one call (gpt-4o-mini, ~1–2 s)
POST/projects/extract-intentLLM extracts problem count from free-text prompt (gpt-4o-mini, ~1 s, used by toolbar shortcuts)
POST/projects/from-promptCreate new project via Vega agent (120 s)
POST/projects/{id}/update-from-promptAdd problems to existing project via Vega agent (120 s)
GET/projects/List user's projects
PUT/projects/{id}Add problem IDs to a project (called by Vega internally)
DELETE/projects/{id}Delete project and its submissions
GET/projects/{id}/problemsFetch problems in a project (used by update path)
POST/projects/{id}/set-defaultSet active project for the user
VEGA SERVICE (internal)
POST/parse-messagegpt-4o-mini → {intent: create|update|unclear, total: int|null}
POST/extract-intentgpt-4o-mini → {total: int|null}
POST/generateRun full LangGraph agent pipeline
GET/healthHealthcheck

LLM Strategies (pick_strategy node)

Strategy Trigger Behaviour
warmup New user, "easy", "getting started" All-easy distribution
weakness_fix "improve", "weak areas", interview prep Heavy weight on lowest-accuracy tags
topic_focus User names topics ("DP", "graphs") Restricts to focus_tags only
revision "review", "revise", "revisit" Balanced over attempted weak tags
mixed Default / LLM fallback Balanced across all difficulties & tags
